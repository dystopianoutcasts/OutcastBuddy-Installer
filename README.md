# Outcast Overclock installer

This is the installer for **Outcast Overclock** (formerly Outcast Checkpoint, and before that Outcast Buddy), the helper that lets Project Zomboid load the Java parts of the Dystopian Outcasts mods (like the Outcast Viewpoint first-person view and our loading screen). It runs on Windows, Linux (including the Steam Deck) and Mac.

**Get it:** download the file for your computer from [the latest release](https://github.com/dystopianoutcasts/OutcastOverclock-Installer/releases/latest):

- Windows: `OutcastOverclockInstaller.exe`
- Linux and the Steam Deck: `outcast-overclock-installer-linux-amd64.tar.gz`
- Mac: `outcast-overclock-installer-mac.zip`

Older releases use older names: `OutcastCheckpointInstaller.exe` (3.0.0-beta19 to beta22) and `OutcastBuddyInstaller.exe` (before beta19). They are the same program under earlier names.

**How it works:**
1. Subscribe to Outcast Overclock on the Steam Workshop and let Steam finish downloading it.
2. Close Project Zomboid.
3. Run the installer and click **Install Outcast Overclock**.

The installer copies the helper into your Project Zomboid folder and sets the game to load it. It backs up everything it changes, and **Uninstall** puts it all back. If you installed an earlier version (Outcast Checkpoint or Outcast Buddy), it moves you to the new names in place. Updates come through your Workshop subscription, so you only run the installer once.

The step-by-step guide is the "Install Instructions" file inside the mod's folder, and on [dystopianoutcasts.online/buddy](https://dystopianoutcasts.online/buddy).
