# Outcast Checkpoint installer

This is the Windows installer for **Outcast Checkpoint** (formerly Outcast Buddy), the helper that lets Project Zomboid load the Java parts of the Dystopian Outcasts mods (like the Outcast Viewpoint first-person view and our loading screen).

**Get it:** download `OutcastCheckpointInstaller.exe` from [the latest release](https://github.com/dystopianoutcasts/OutcastBuddy-Installer/releases/latest). Releases before 3.0.0-beta19 call the file `OutcastBuddyInstaller.exe`; it is the same program under its old name.

**How it works:**
1. Subscribe to Outcast Checkpoint on the Steam Workshop.
2. Close Project Zomboid.
3. Run `OutcastCheckpointInstaller.exe` and click **Install**.

The installer copies two files into your Project Zomboid folder and sets the game to load them. It backs up everything it changes, and **Uninstall** puts it all back. Updates come through your Workshop subscription, so you only run the installer once.

The step-by-step guide is the "Install Instructions" file inside the mod's folder, and on [dystopianoutcasts.online/buddy](https://dystopianoutcasts.online/buddy).

Questions? Find us on the Dystopian Outcasts Discord. We're happy to help.
